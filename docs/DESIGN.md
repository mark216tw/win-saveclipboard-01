# 系統設計文件

本文件說明 SaveClipboard 的產品目標、使用案例、介面設計、資料模型、狀態流程、錯誤處理與設計決策。若需了解實際程式分層與服務互動，請搭配 [系統架構與技術文件](ARCHITECTURE.md) 閱讀。

## 1. 產品目標

SaveClipboard 的目標是成為一個**低干擾、可快速叫用、重視隱私**的 Windows 剪貼簿歷史工具：

- 常駐系統匣，不佔用工作列與桌面空間。
- 用一個快捷鍵或一次點擊就能找到剛剛複製的內容。
- 點選歷史項目即可重新複製，必要時自動貼回前一個視窗。
- 預設不把剪貼簿內容寫入磁碟，降低敏感資料外洩風險。
- 尊重來源應用程式「不要記錄」的標記。
- 在 Windows 10／11、不同 DPI 與多螢幕環境下維持可用的面板位置。

### 非目標

- 不成為完整的密碼管理器或檔案管理工具。
- 不取代 Windows 內建的剪貼簿歷史（`Win+V`），而是提供更直接的面板與貼上流程。
- 不提供雲端同步、跨裝置同步或帳號系統。
- 不提供安裝檔、系統服務或驅動程式。
- 不支援 Windows 10 1809 以下的系統。

| 使用者 | 情境 | 需求 |
| --- | --- | --- |
| 一般辦公使用者 | 反覆複製貼上地址、Email、表單內容 | 快速找回前幾筆文字，點一下就貼上 |
| 開發者 | 複製程式碼片段、指令、錯誤訊息 | 搜尋、釘選常用片段、保留長文字 |

## 5. 使用案例

### UC-01 快速貼上剛才複製的文字

1. 使用者在瀏覽器複製一段地址。
2. 切換到表單欄位。
3. 按 `Ctrl+Alt+V` 開啟面板。
4. 點擊最上方項目。
5. 程式將文字寫入剪貼簿、切回表單視窗並送出 `Ctrl+V`。
6. 面板依設定隱藏或保持顯示。

**例外**：表單視窗以系統管理員權限執行 → 只複製，系統匣提示無法自動貼上。

### UC-02 找回稍早複製的內容

1. 開啟面板。
2. 在搜尋列輸入關鍵字。
3. 清單即時過濾文字項目。
4. 按 `↓` 進入清單，用 `↑`／`↓` 選擇。
5. 按 `Enter` 複製並貼上。

### UC-03 釘選常用片段

1. 勾選一或多個項目。
2. 按標題列釘選按鈕。
3. 項目移到清單最上方並顯示釘選徽章。
4. 之後即使超過保存上限，釘選項目仍保留。

### UC-04 刪除並復原

1. 勾選項目後按刪除，或對焦後按 `Delete`。
2. 確認對話框按「刪除」。
3. 左下角顯示「已刪除 N 個項目」與「復原」。
4. 5 秒內按「復原」，項目回到原位置。

### UC-05 暫停記錄敏感內容

1. 從系統匣選單選擇「暫停記錄 30 分鐘」。
2. 系統匣提示變為「記錄已暫停」。
3. 處理密碼或機密資料；期間複製內容不進入歷史。
4. 30 分鐘後自動恢復，或再次選單選擇「恢復記錄」。

### UC-06 跨啟動保留歷史

1. 設定頁勾選「保存歷史到本機（加密）」。
2. 按「儲存」。
3. 程式以 DPAPI 加密寫入 `history.dat`。
4. 下次啟動自動載入並解密。
5. 取消勾選並儲存 → 刪除 `history.dat`。

### UC-07 開機自動啟動

1. 設定頁勾選「開機自動啟動」並儲存。
2. 程式寫入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值為 `"<exe>" --autostart`。
3. 下次登入時程式只常駐系統匣，不顯示面板。
4. 使用者按快捷鍵或點圖示才會看到面板。

### UC-08 更新版本

1. 結束程式。
2. 下載新 zip 並覆蓋程式資料夾。
3. 設定與歷史位於使用者資料夾，不受影響。
4. 重新啟動。

### 6.2 設定頁

設定頁以覆蓋方式顯示，分為：

1. 啟動（開機自動啟動、面板置頂、選取後直接貼上）
2. 顯示模式
3. 主題顏色
4. 歷史保存
5. 保存上限
6. 主視窗關閉
7. 全域快捷鍵
8. 關於（版本、隱私、授權、日誌、重設）

底部固定「關閉」與「儲存」按鈕。設定頁開啟時按全域快捷鍵會收起面板並放棄未儲存變更。

### 6.3 視覺規範

- 間距以 4 的倍數為基準；圓角 8（小元件 4–6）。
- 顏色定義於 `Styles/Themes/CommonBrushes.xaml`，使用 `ThemeResource`。
- 字型大小集中於 `Styles/TextStyles.xaml` 與各層級樣式。
- 圖示按鈕需有 `AutomationProperties.Name` 與 `ToolTipService.ToolTip`。
- 破壞性操作使用 `ContentDialog` 二次確認。
- 空狀態、載入狀態、錯誤提示皆有畫面。

### 6.4 無障礙設計

- 清單項目的 CheckBox `AutomationProperties.Name` 綁定項目預覽。
- 面板主要控制項有 `AutomationId`（`SearchBox`、`ClosePanelButton`、`PauseButton`、`ClearAllButton`）。
- 設定儲存錯誤使用 `AutomationProperties.LiveSetting="Assertive"`。
- 高對比模式使用系統色彩，不強制套用主題色。
- `Tab` 順序依視覺順序排列。

## 7. 狀態設計

### 7.1 面板顯示狀態

```text
            ┌──────────────┐
            │    Hidden    │◀────────────────────┐
            └──────┬───────┘                     │
     顯示請求      │                             │
     (快捷鍵/圖示)  ▼                             │
            ┌──────────────┐   失去焦點/Esc/X    │
            │   Visible    │─────────────────────┤
            └──────┬───────┘                     │
                   │ 設定頁                       │
                   ▼                             │
            ┌──────────────┐   關閉/快捷鍵        │
            │ SettingsPage │─────────────────────┘
            └──────────────┘
```

規則：

- 自動關閉模式下，面板取得前景後若失焦，會延遲隱藏；延遲期間重新取得焦點則取消。
- 手動關閉模式下，失焦不隱藏。
- 貼上期間以 `_pasteInProgress` 抑制失焦隱藏。
- 設定頁開啟時按快捷鍵：先復原設定再隱藏。
- 確認對話框開啟時忽略快捷鍵與關閉請求。

### 7.2 記錄狀態

```text
     ┌──────────┐   暫停 30 分鐘   ┌──────────┐
     │Recording │─────────────────▶│  Paused  │
     └────┬─────┘                  └────┬─────┘
          │◀────────────────────────────┘
          │        恢復／到期
          ▼
   收到 WM_CLIPBOARDUPDATE → 檢查暫停 → 略過或排入擷取
```

- 暫停狀態只存在記憶體，程式結束後消失。
- 到期時間以 `DateTimeOffset.Now` 計算，查詢時判斷，不需背景計時器。
- 系統匣提示與面板底部按鈕會同步顯示狀態。

### 7.3 歷史項目狀態

```text
   新增 ──▶ 未釘選（頂端）
              │ 釘選
              ▼
          已釘選（釘選區）
              │ 取消釘選
              ▼
          未釘選（依時間排序）
              │ 刪除
              ▼
          已刪除（5 秒復原視窗）
              │ 復原
              ▼
          回到原索引
```

## 8. 資料設計

### 8.1 設定資料

`AppSettings` 欄位：

| 欄位 | 型別 | 預設 | 說明 |
| --- | --- | --- | --- |
| `MaxItems` | `int` | 30 | 未釘選項目上限，10–50 |
| `AutoStart` | `bool` | false | 開機自動啟動 |
| `DisplayMode` | `DisplayMode` | System | 顯示模式 |
| `ThemeId` | `string` | classic-blue | 主題識別碼 |
| `CloseBehavior` | `WindowCloseBehavior` | Auto | 關閉方式 |
| `PasteOnSelect` | `bool` | true | 選取後直接貼上 |
| `AlwaysOnTop` | `bool` | false | 面板置頂 |
| `PersistHistory` | `bool` | false | DPAPI 加密保存 |
| `HasSeenWelcome` | `bool` | false | 是否看過首次導引 |
| `HasPanelBounds` | `bool` | false | 是否保存過面板位置 |
| `PanelLeft` / `PanelTop` | `int` | 0 | 面板左上角（實體像素） |
| `PanelWidth` / `PanelHeight` | `int` | 400 / 620 | 面板尺寸（實體像素） |
| `PanelDpi` | `int` | 96 | 保存時的螢幕 DPI |

`Normalize()` 會：

- 夾限 `MaxItems`、面板尺寸與 DPI。
- 驗證 `DisplayMode`、`CloseBehavior`、`ThemeId`。
- 若 `HasPanelBounds=false`，重設位置與尺寸為預設值。

### 8.2 歷史資料

記憶體中使用 `ObservableCollection<ClipboardEntry>`；加密保存時序列化為：

```json
{
  "Version": 1,
  "Entries": [
    {
      "Id": "guid",
      "Kind": "Text",
      "Text": "內容",
      "ImageBase64": null,
      "ThumbnailBase64": null,
      "PixelHashBase64": null,
      "Key": "T:...",
      "CopiedAt": "2026-11-16T00:00:00+08:00",
      "IsPinned": false
    }
  ]
}
```

整份 JSON 經 DPAPI 加密後才寫入磁碟。

### 8.3 資料生命週期

| 資料 | 建立 | 保存 | 刪除 |
| --- | --- | --- | --- |
| 記憶體歷史 | 複製內容 | 程式執行期間 | 清除全部、刪除、淘汰、結束程式 |
| `settings.json` | 按「儲存」 | 跨啟動 | 手動刪除 |
| `history.dat` | 啟用加密保存 | 跨啟動 | 關閉選項、手動刪除 |
| `app.log` | 執行期間 | 1 MB 輪替 | 手動刪除 |
| `crash.log` | 未處理例外 | 1 MB 上限 | 手動刪除 |
| `settings.corrupt-*.json` | 設定損毀 | 永久（直到手動刪除） | 手動刪除 |

## 9. 錯誤處理與復原

| 情境 | 處理 |
| --- | --- |
| 剪貼簿被其他程式占用 | `ClipboardRetry` 重試 3 次（40／80 ms） |
| WinRT `GetTextAsync` 失敗或格式為空 | 改用 Win32 `CF_UNICODETEXT` |
| 剪貼簿來源無回應 | 15 秒逾時，記錄並處理下一筆 |
| 待處理佇列過長 | 丟棄最舊序號並記錄 |
| 圖片解碼失敗 | 記錄警告，略過該筆 |
| 寫入剪貼簿失敗 | 面板顯示「複製失敗，請再試一次」 |
| 自動貼上失敗 | 保留剪貼簿內容，系統匣氣泡提示 |
| 設定儲存失敗 | 留在設定頁並顯示原因 |
| 設定檔損毀 | 備份原檔，以預設值啟動，設定頁提示 |
| 歷史解密失敗 | 記錄警告，以空白歷史啟動 |
| 日誌寫入失敗 | 不影響主流程；下次可再寫 |
| 未處理例外 | 可復原類型（COM／IO／權限）吞掉並記錄；其餘記錄後結束 |
| Explorer 重啟 | 處理 `TaskbarCreated`，重新加入系統匣圖示 |

### 9.1 例外分類

`App.IsRecoverable` 將以下例外視為可復原：

- `COMException`
- `IOException`
- `UnauthorizedAccessException`

其他例外會寫入 `crash.log` 後讓程式結束，避免在損毀狀態下繼續執行。

## 10. 隱私與安全設計

### 10.1 隱私標記

| 格式 | 判定 |
| --- | --- |
| `ExcludeClipboardContentFromMonitorProcessing` | 一律不記錄 |
| `CanIncludeInClipboardHistory` = 0 | 不記錄 |
| `CanIncludeInClipboardHistory` 缺失或非 0 | 依一般流程記錄 |
| 格式清單無法取得 | 以 Win32 再檢查上述標記 |

### 10.2 資料最小化

- 日誌只記錄事件與長度，不記錄內容。
- 文字鍵值使用 SHA256，不重複保存完整文字。
- 預設不寫入歷史檔。
- 加密保存使用目前使用者範圍的 DPAPI。

### 10.3 威脅模型

| 威脅 | 緩解 |
| --- | --- |
| 其他程式讀取歷史檔 | DPAPI 加密；僅目前使用者可解密 |
| 日誌洩漏內容 | 日誌不記錄剪貼簿內容 |
| 密碼管理器內容被記錄 | 尊重來源隱私標記 |
| 高權限視窗被自動貼上 | UIPI 阻擋；程式只複製並提示 |
| 設定檔被竄改 | `Normalize()` 驗證列舉與範圍 |
| 程式當機造成設定損毀 | 先寫 `.tmp` 再置換；損毀時備份 |

## 11. 設計決策

### D-01 使用 WinUI 3 而非 WPF／WinForms

- 優點：原生 Fluent 外觀、Windows App SDK 整合、支援淺色／深色與高對比。
- 缺點：未封裝模式仍需處理部分資源與視窗限制；系統匣需 P/Invoke。
- 結論：符合現代 Windows 桌面應用需求，系統匣以 `Shell_NotifyIcon` 補足。

### D-02 常駐系統匣而非工作列視窗

- 降低干擾，符合工具型應用定位。
- 以 `HelperWindow` 接收原生訊息，面板僅在使用時顯示。

### D-03 預設只存記憶體

- 降低敏感資料落盤風險。
- 需要跨啟動保留時，由使用者明確選擇 DPAPI 加密保存。

### D-04 以剪貼簿序號抑制自我更新

- 舊版以時間窗判斷，容易在快速操作時誤判。
- 以 `GetClipboardSequenceNumber` 精確比對本程式寫入造成的更新，避免重複收錄。
- 序號為 0 時不抑制，寧可多一筆重複也不漏記。

### D-05 擷取改為 FIFO 佇列 + 逾時

- 解決連續複製只留第一筆／最後一筆的問題。
- 避免來源程式無回應造成永久停擺。
- 上限 8 筆，超過丟棄最舊，控制記憶體與延遲。

### D-06 圖片在背景處理

- 解碼、PNG 編碼、縮圖與雜湊可能耗時。
- 移到 `Task.Run`，完成後才回 UI 執行緒加入集合，避免面板卡頓。

### D-07 面板位置以實體像素保存並依 DPI 換算

- Windows 多螢幕與縮放比例差異大。
- 保存 `PanelDpi`，還原時換算並夾限工作區，避免跑出畫面。

### D-08 貼上目標使用前景事件追蹤

- 點擊工作列或系統匣時，前景可能先變成殼層，當下抓不到真正的前一個 App。
- 以 `SetWinEventHook` 持續記錄最後一個外部可見前景視窗，作為備援。

### D-09 主題與樣式集中管理

- 避免 XAML 硬編碼顏色。
- 以 `ThemeResource` 即時切換，支援淺色、深色與高對比。

### D-10 資源字串化

- 主要 UI 文案放在 `.resw`，預設繁體中文，附英文資源。
- 便於未來新增語系與維持一致性。

## 12. 限制與取捨

- 未提供程式碼簽章與安裝檔，首次執行需通過 SmartScreen。
- 未在 Windows 10 1809 實機完整驗證；部分行為以程式邏輯與單元測試驗證。
- 自動貼上依賴前景切換與 `SendInput`，無法突破 UIPI。
- 加密歷史在 UI 執行緒同步解密，超大歷史可能延長啟動時間。
- Shift 多選以目前可見清單為範圍，不跨搜尋結果。
- 圖片只支援 WinRT 可取得的點陣圖格式；Win32 後援僅文字。
- 日誌為非同步批次寫入，強制結束時可能遺漏最後幾筆。

## 13. 後續發展方向

以下為可能方向，非目前版本承諾：

- 以 `Microsoft.Data.Sqlite` 或輕量索引改善大量歷史的搜尋效能。
- 增加更多語系資源。
- 提供可選的程式碼簽章與 MSIX 封裝。
- 增加圖片縮放預覽與更多鍵盤快捷操作。
- 增加匯出／匯入歷史（需明確加密與隱私設計）。
- 改善 Windows 10 1809 與 ARM64 實機驗證流程。
