# 使用指南

本指南說明 SaveClipboard 的安裝、操作與設定。SaveClipboard 是常駐系統匣的剪貼簿歷史工具，沒有傳統主視窗；所有操作都從彈出面板與系統匣選單開始。

## 1. 系統需求

| 項目 | 需求 |
| --- | --- |
| 作業系統 | Windows 10 1809（10.0.17763）以上 |
| 架構 | x64 或 ARM64 |
| .NET | .NET 10 Desktop Runtime |
| Windows App SDK | Windows App SDK 1.8 Runtime |

本專案 Release 提供的 zip 為 **framework-dependent（非 Self-Contained）**，不含上述執行環境。若缺少 Runtime，執行程式時會出現錯誤或無法啟動。

## 2. 下載與安裝

1. 開啟 [最新版本 Release](https://github.com/mark216tw/win-saveclipboard-01/releases/latest)。
2. 依裝置下載 `SaveClipboard-<版本>-win-x64.zip` 或 `SaveClipboard-<版本>-win-arm64.zip`。
3. 將 zip 解壓縮到您有寫入權限的資料夾，例如 `C:\Apps\SaveClipboard`。
4. 直接執行 `SaveClipboard.exe`。

本專案**不提供安裝檔**，也不會寫入 Program Files 或註冊卸載項目。要移除程式時，先從系統匣選單結束程式，再刪除解壓縮資料夾即可。

### SmartScreen 提示

目前版本未進行程式碼簽章，首次執行可能出現「Windows 已保護您的電腦」。請確認檔案來自本專案 GitHub Release，然後選擇「更多資訊」→「仍要執行」。

### 系統匣圖示看不到

Windows 11 預設會將新圖示收在系統匣溢出區（^）。請點擊工作列右下角的 `^`，將 SaveClipboard 圖示拖到工作列，或在工作列設定中調整顯示。

## 3. 啟動與結束

- **手動啟動**：執行 `SaveClipboard.exe` 後會直接顯示面板。
- **開機自動啟動**：在設定頁勾選「開機自動啟動」並儲存。之後登入 Windows 時程式會只常駐系統匣，不彈出面板。
- **重複啟動**：程式採單一實例；已在執行時再次啟動，會喚起既有面板後結束第二個實例。
- **結束程式**：在系統匣圖示按右鍵，選擇「結束」。關閉面板不等於結束程式。

## 4. 開啟與收起面板

| 方式 | 行為 |
| --- | --- |
| `Ctrl+Alt+V` | 面板隱藏時開啟；已顯示時收起 |
| 系統匣圖示左鍵 | 只開啟面板；收起請按面板右上角 X、`Esc` 或快捷鍵 |
| 工作列釘選圖示 | 開啟面板 |
| 重複啟動 `SaveClipboard.exe` | 喚起既有面板 |

面板會優先出現在系統匣圖示附近；若抓不到圖示位置，會改為出現在游標所在螢幕的右下角。面板位置與大小會被記住，下次開啟時依目前螢幕與 DPI 調整到可見工作區內。

## 5. 面板介面

面板由上到下分為四個區域：

1. **標題列**：App 圖示、標題、釘選選取、刪除選取、設定、關閉；按住標題列空白處可拖曳移動面板。
2. **搜尋列**：輸入關鍵字即時過濾文字項目；右側有清除按鈕。
3. **歷史清單**：每列包含勾選框、文字圖示或圖片縮圖、釘選徽章、預覽與複製時間。
4. **底部列**：項目數與圖片用量、暫停記錄按鈕、清除全部按鈕。

圖片項目會顯示縮圖；釘選項目在縮圖右下角顯示釘選徽章，並固定在清單最上方。

## 6. 基本操作

### 複製歷史項目

點擊項目內容即可將該項目重新寫入剪貼簿。預設在複製成功後收起面板；若啟用「選取後不關閉視窗」，面板會保持顯示。程式不會自動貼回前一個視窗，請自行在目標視窗按 `Ctrl+V`。

### 搜尋

- 輸入關鍵字即時過濾**文字**項目；圖片項目不參與文字比對。
- 比對忽略大小寫與前後空白。
- 按 `Esc` 先清除搜尋；搜尋已空白時再按 `Esc` 會關閉面板。

### 選取、釘選與刪除

- 每列左側的 CheckBox 用於多選。
- 勾選後，標題列的釘選按鈕與刪除按鈕會變為可用。
- 釘選項目不受保存上限淘汰，且固定顯示在最上方。
- 刪除需要二次確認；刪除後 5 秒內可從左下角提示按「復原」。
- 「清除全部」會刪除所有歷史（含釘選），同樣需要二次確認。

### 暫停記錄

需要處理敏感內容時，可暫停記錄 30 分鐘：

- 系統匣右鍵選單選擇「暫停記錄 30 分鐘」。
- 或按面板底部的暫停按鈕。

暫停期間新的剪貼簿內容不會進入歷史；時間到會自動恢復。系統匣提示文字會顯示目前是否暫停。

### 移動與調整面板大小

按住標題列空白處（標題文字或 App 圖示皆可，按鈕除外）拖曳即可移動面板；拖曳面板邊緣可調整大小，最小為 320×400 DIP。拖曳結束、關閉面板或結束程式時會保存位置、大小與 DPI；下次開啟時會依目前螢幕工作區驗證，避免跑出畫面。

## 7. 鍵盤操作

| 按鍵 | 功能 |
| --- | --- |
| `Ctrl+Alt+V` | 全域切換面板顯示／隱藏 |
| `Esc` | 清除搜尋；再按一次關閉面板 |

面板內的清單導覽與項目操作請使用滑鼠。在設定頁開啟時按全域快捷鍵，會收起面板並放棄尚未儲存的設定。

## 8. 設定頁

按面板右上角齒輪圖示開啟設定頁。設定分為以下區塊：

### 啟動

| 設定 | 說明 | 預設 |
| --- | --- | --- |
| 開機自動啟動 | 登入後自動常駐系統匣 | 關閉 |
| 選取後不關閉視窗 | 複製項目後保持面板顯示 | 關閉 |

面板固定置頂；複製成功後預設會收起，除非啟用「選取後不關閉視窗」。

### 顯示模式

- 跟隨系統：依 Windows 淺色／深色設定自動切換。
- 淺色。
- 深色。

切換後立即預覽；按「儲存」才會寫入設定。

### 主題顏色

提供 10 款主題色：經典藍、森林綠、暮色紫、暖陽橙、玫瑰紅、湖水青、金黃、石墨灰、靛青、珊瑚紅。每款主題都有淺色與深色變體；高對比模式會改用系統色彩。

### 歷史保存

「保存歷史到本機（加密）」開啟後，整份歷史會使用 Windows DPAPI（目前使用者）加密寫入 `%LOCALAPPDATA%\SaveClipboard\history.dat`。關閉此選項並儲存後，程式會刪除該檔案。

詳細資料處理方式請見 [隱私與資料處理](PRIVACY.md)。

### 保存上限

以 10 為單位在 10–50 之間調整，預設 30。上限只計算**未釘選**項目；圖片另有 100 MB 總量上限。

### 面板關閉方式

面板固定為手動關閉：點擊其他視窗不會自動收起，按 X、`Esc`（搜尋已空白時）或全域快捷鍵即可關閉。

### 全域快捷鍵

固定為 `Ctrl+Alt+V`。若被其他程式占用，設定頁會顯示提示；此時可關閉占用該組合的程式後重新啟動 SaveClipboard。

### 關於

顯示版本、檔案版本、隱私說明、授權與日誌資料夾入口。也可在此「重設為預設值」。

## 9. 設定儲存與復原

- 按「儲存」才會寫入 `%AppData%\SaveClipboard\settings.json` 與開機啟動登錄值。
- 按「關閉」會放棄本次未儲存的變更，並復原顯示模式與主題預覽。
- 儲存失敗（例如磁碟空間不足、資料夾權限不足）時，設定頁會留在原畫面並顯示原因。
- 設定檔損毀時，程式會將原檔備份為 `settings.corrupt-<時間>.json`，以預設值啟動，並在設定頁顯示提示。

## 10. 更新版本

1. 從系統匣選單結束 SaveClipboard。
2. 下載新版本 zip。
3. 解壓縮並覆蓋原資料夾（設定與歷史檔案位於使用者資料夾，不會被覆蓋）。
4. 重新執行 `SaveClipboard.exe`。

## 11. 解除安裝

1. 在設定頁取消「開機自動啟動」並儲存（或手動移除登錄值）。
2. 從系統匣選單結束程式。
3. 刪除程式資料夾。
4. 視需要刪除使用者資料：
   - `%AppData%\SaveClipboard`
   - `%LOCALAPPDATA%\SaveClipboard`

## 12. 常見問題

### 面板打開後立刻消失

面板不會因失焦自動關閉。若面板消失，通常是按了 `Esc`、全域快捷鍵，或複製成功後依設定自動收起；可啟用「選取後不關閉視窗」保留面板。

### 選取後沒有貼上

- 本版本點選項目只會複製到剪貼簿，不會自動貼回前一個視窗。
- 請切回目標視窗後自行按 `Ctrl+V`。

### 快捷鍵沒有反應

`Ctrl+Alt+V` 可能被其他程式占用。開啟設定頁查看「全域快捷鍵」狀態；關閉占用程式後重新啟動 SaveClipboard。

### 圖片沒有出現在歷史

- 圖片歷史有 100 MB 總量上限，過舊的未釘選圖片會被淘汰。
- 部分應用程式以延遲格式提供圖片，或將內容標記為不記錄。
- 來源程式暫時無回應時，擷取會在 15 秒後逾時並繼續下一筆。

### 歷史在重新啟動後消失

這是預設行為：歷史只保存在記憶體。若需要跨啟動保留，請在設定頁開啟「保存歷史到本機（加密）」。

### 日誌在哪裡

`%LOCALAPPDATA%\SaveClipboard\Logs\`。設定頁的「開啟日誌資料夾」可直接開啟。日誌不含剪貼簿內容。

### 為什麼沒有安裝檔

本專案以未封裝模式發佈，提供可攜式 zip 為主要形式，不建立 MSIX 安裝檔，也不寫入系統安裝目錄。

## 13. 已知限制

- 未在 Windows 10 1809 實機完整驗證；建議使用 Windows 11。
- 高 DPI、多螢幕與高對比模式主要透過程式邏輯與單元測試驗證，實際外觀仍依裝置而異。
- 未提供程式碼簽章，首次執行需通過 SmartScreen 提示。
